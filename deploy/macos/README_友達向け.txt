================================================================
  Antigravity 日本語版（Mac ネイティブアプリ）はじめにお読みください
================================================================

このアプリは、あなたの Mac に入っている Google Antigravity に直結して動く
「完全日本語 UI の超軽量 Mac ネイティブアプリ」です。
別途 Gemini API キーの取得や追加課金は必要ありません。

■ 必要なもの
1. macOS 13 (Ventura) 以降（Apple Silicon / Intel Mac 両対応）
2. Google Antigravity がインストール・ログイン済みであること
3. Node.js（v22 以上）
   ※ 未導入の場合は https://nodejs.org/ から LTS 版をインストールしてください

■ かんたんセットアップ手順（約1分）
1. このフォルダの中にある「セットアップ.command」をダブルクリックします。
   ※「開発元を確認できないため開けません」と出た場合：
     「セットアップ.command」を右クリック（または Control+クリック）→「開く」→「開く」を選んでください。
2. 画面の案内に従って Enter を押すと、以下が自動で完了します：
   ・/Applications/Antigravity日本語版.app のインストール
   ・AI の返答や計画書まで日本語にするグローバルルールの設定（任意）
3. 完了すると「Antigravity 日本語版」が自動で起動します！
   次回からはアプリケーションフォルダや Spotlight から普通に起動できます。

■ 主な機能（v1.3.0 統合エディション：シンプル版 ⇄ マルチAI上位版）
・設定画面で「🌿 シンプル版（Gemini専用）」と「⚡ マルチAI版（上位）」をワンクリック切替
・上位モードでは OpenAI（ChatGPT / Codex CLI）・Anthropic（Claude Code CLI）・ローカル Ollama を各社公式ブラウザログインで追加して利用可能
・上位モードの「⚖️ 並列比較」で複数AIへ同時質問して回答を横並び（スマホは縦並び）比較、1タップ指示プリセット・Markdown描画・コピー・再試行に対応
・メニュー・チャット・設定・承認カードまで 100% 日本語 UI（PC / スマホ両対応）
・AI の重み＆残り枠の見える化（コンテキスト重みバッジ・Gemini 残り枠％・直近7日間のトークン推移）
・整理されたチャット一覧（1本スクロール・ピン留め・実行中・プロジェクト別グループ・親チャット配下の子チャット階層ツリー・日本語自動タイトル化）
・自分のコメントをその場でインライン編集して巻き戻し再送信（編集 → 保存して再送信 / キャンセル）
・枝分かれチャット（🌿）で本流の記憶を汚さずに別チャットや他社AIへ仮説検証を分岐可能
・サイドバーからのエージェント＆タスク監視、右ペイン「アーティファクトビューア（Markdown / Mermaid図 / CSV / 画像 / PDF）」
・⌘K コマンドパレットでチャット移動・ファイル閲覧・音声入力・新規指示を即呼び出し
・読みやすいチャット表示（AI の返答コメントは枠なし表示、作業内容・思考プロセスはスッキリ折りたたみ）
・チャット入力バーにモデル選択・高速/計画モード・ローカル実行権限・マイク音声入力を搭載
・日本語 IME 変換確定時の Enter 誤送信を防止（Enter で送信 / Shift+Enter で改行）
・ファイルやフォルダをチャット欄へドラッグ＆ドロップすると自動でパス挿入（画像は画像添付）
・作業完了時の通知＆作業中の Mac スリープ防止（上部メニュー「表示」から ON/OFF）
・設定画面から「AI 応答の日本語ルール（~/.gemini/GEMINI.md）」をいつでもワンクリック適用可能

■ 自分の AI に改造させたい時
公式 GitHub リポジトリ（ソースコード＆AI改造ガイド同梱）:
  https://github.com/ohtake01-cell/antigravity-jp
リポジトリ内の AI_CUSTOMIZE_GUIDE.md を自分の AI エージェントに読ませれば、
色やレイアウト変更・機能追加・再ビルドまでそのまま依頼できます。

■ トラブル対処
・「Antigravity エンジンを探しています…」と表示されたままのとき：
  本家の Google Antigravity（または Antigravity IDE）を一度起動してログイン済みか確認してください。
・うまく繋がらないとき：
  上部メニューの「ファイル」→「ローカルサーバーを再起動」を試してください。
  ログは ~/Library/Logs/AntigravityJP/server.log に記録されます。
・消したくなったとき：
  「アンインストール.command」をダブルクリックすれば綺麗に削除できます
  （本家 Antigravity や会話履歴は一切消えません）。
